# The joke the reviewer laughs at

Entry for the [make.fun](https://make.fun) bounty
[The joke the reviewer laughs at](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329):
a program (`main.py`, Python 3.13 stdlib only) that writes one one-line joke
about working beside AI coding agents to `/output/entry.txt`.

The joke: an agent rewrites the function, the tests and the commit message —
but leaves the human's name on the blame, so when it breaks at 3 a.m. it's
still the human's phone that rings.

Run it: `python3 main.py` (writes `/output/entry.txt`, deterministic).
